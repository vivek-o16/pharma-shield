    WHY PHARMA SHIELD?

    The problem, the solution, the impact

    The problem

    CDSCO drug-quality reports contain important information, but searching through large reports manually can be time-consuming.

    The solution

    Pharma Shield provides a simple medicine and batch-based search interface to quickly identify matching quality-alert records.

    The impact

    Users can quickly locate relevant records and verify the information against official CDSCO sources.

    THE PROJECT

    Built to make drug-alert information easier to check.

    Pharma Shield is an educational drug-quality awareness platform for quickly searching medicine and batch information against the dataset included with this project.

    The dataset bundled with this project is organized from official CDSCO drug-quality alert publications. Pharma Shield does not certify medicines as safe — always verify important findings against the official CDSCO source.
