THE PROJECT

Built to make drug-alert information easier to check.

Pharma Shield is an educational drug-quality awareness platform for quickly searching medicine and batch information against the dataset included with this project.

The current JSON supplied with the project is explicitly marked as illustrative demo data. It should be replaced with an authentic, verified CDSCO-sourced dataset before real-world use.

IMPORTANT

Educational project — not a safety certificate.
